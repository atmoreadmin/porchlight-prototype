# Porchlight — working prototype

A phone-friendly prototype for selling as-is homes to verified cash buyers, with three views:

- **Seller**: home details → condition → investor pricing (70% and 1% rules) → offers → timeline to closing
- **Buyer**: get verified → deal feed → deal math (flip / rental) → make an offer
- **Team**: pipeline, value-review requests, offer comparison, house offers, notes

## Important

- **Test data only.** Everything is saved in the browser on the device you use (localStorage). Nothing is sent to a server, and each phone has its own copy.
- Estimates use placeholder rules (ARV = $250/sq ft, set repair costs per item). A real data feed replaces these later.
- "Reset all demo data" on the home screen restores the sample deals.

## Run it

Open `index.html` in a browser, or turn on GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).
